# Intake and diagnosis

用于在生成学习文档前诊断用户真实基础。目标：不要让用户自报“懂/不懂”，而是用具体问题测出前置知识、误解、卡点和用途。

## Core rule

凡属于下面问题类型，优先用 AskUserQuestion。只有用户已经明确给出答案时才跳过。不要在正文里模拟问答、列完选项后自己给答案、写“参考答案/参考判断”。必须等待用户选择后再生成学习文档。

一次 AskUserQuestion 最多 2-4 个问题。优先顺序：前置知识 → 当前误解 → 例子判断 → 输出目标/深度 → Markdown 沉淀。

## 必须显式使用 AskUserQuestion 的问题类型

1. **前置知识诊断**：决定从哪里讲起。
   - 选项必须是具体前提概念，不要只写“零基础/有基础”。

2. **当前理解/误解定位**：决定先纠偏还是直接讲定义。
   - 选项包含正确说法、常见误解、边界情况和“不确定”。

3. **具体卡点**：决定文档重心。
   - 例如：为什么出现 / 定义符号 / 推导跳步 / 会例题不会迁移。

4. **例子判断/预测题**：暴露真实理解。
   - 用最小场景让用户判断能不能用该概念/方法。
   - 必须通过 AskUserQuestion 提问，不能在正文里自问自答。

5. **输出目标**：决定产物类型。
   - 例如：打通直觉 / 搞懂推导 / 会做题 / 考前复习。

6. **输出深度**：决定认知负荷。
   - 例如：30 秒版 / 标准版 / 深度版 / 复习版。

7. **Markdown 沉淀选择**：决定是否给文件名、放置位置和整理建议。
   - 需要沉淀 / 先不沉淀 / 你来判断 / 合并旧笔记。

8. **题目或材料处理方式**：用户贴题目、错题、教材片段时必须问。
   - 只讲懂这一题 / 提炼成一类题 / 找错因卡点 / 改写成可沉淀学习文档。

## 不要问

- 纯礼貌问题。
- 可以默认的问题，例如默认中文输出。
- 抽象问题，例如“你想怎么学？”
- 一次性、无分支价值的问题。

## 通用 AskUserQuestion 模板

对任意概念 `[X]`，优先生成类似问题：

1. **前置知识**：学 `[X]` 前，这些基础你哪些已经能说清？
   - `[前提概念 A]`
   - `[前提概念 B]`
   - `[前提概念 C]`
   - 都不太确定

2. **当前理解**：你现在更接近哪种状态？
   - 听过 `[X]`，但说不出它解决什么问题
   - 能背定义，但不知道为什么这么定义
   - 会套公式/步骤，但不会判断什么时候能用
   - 能用，但想补推导、边界和误区

3. **具体卡点**：你最容易卡在哪里？
   - 不知道它为什么出现
   - 不知道它和旧知识的区别
   - 推导/证明看不懂
   - 会做例题，但换题就不会

4. **例子判断**：下面哪个例子/说法你觉得更像 `[X]` 的正确用法？
   - `[正确或接近正确的选项]`
   - `[常见误解选项]`
   - `[边界情况选项]`
   - 不确定

## 考试复习场景

如果用户目标是“考试复习”，不要只问输出深度。考试复习需要知道“考什么、怎么考、怕什么”。若用户说考试范围“不确定”，继续用具体关键词帮他回忆，而不是直接开始写。

必须追加 2-3 个具体问题：

1. **考试题型**：你们考试更像哪类？
   - 名词解释 / 简答题
   - 计算题 / 指标题
   - 算法过程题
   - 综合应用题
   - 不确定，按通用考试复习整理

2. **范围关键词**：你记得课上/教材里出现过哪些内容？
   - `[本学科常见概念组 A]`
   - `[本学科常见算法/方法组 B]`
   - `[本学科常见指标/公式组 C]`
   - 都不确定，按常见考试框架整理

3. **最担心内容**：你最怕哪类？
   - 概念太多，分不清
   - 算法/流程记不住
   - 公式/指标不会算
   - 应用场景不会判断
   - 都不确定

### 数据挖掘考试复习例子

范围关键词：
- 分类、聚类、关联规则、数据预处理
- 决策树、KNN、朴素贝叶斯、K-means、Apriori
- 模型评估、混淆矩阵、准确率、召回率、支持度/置信度/提升度
- 都不确定，按常见数据挖掘考试框架整理

薄弱点：
- 概念分不清：分类/聚类/关联规则/回归
- 算法流程记不住：决策树/K-means/Apriori
- 指标不会算：支持度、置信度、提升度、准确率、召回率
- 应用场景不会判断：给场景不知道选哪个方法

## 示例：时间序列“平稳性”

1. **前置知识**：学平稳性前，这些概念你哪些能说清？
   - 随机变量和随机过程
   - 均值、方差、协方差/自协方差
   - 趋势项、季节性、周期性
   - 都不太确定

2. **当前理解**：你现在更接近哪种说法？
   - 平稳性就是“数据看起来不怎么变”
   - 平稳性是“均值、方差、协方差结构不随时间乱变”
   - 我知道弱平稳/强平稳两个词，但分不清
   - 我会做 ADF 检验，但不懂它检验的是什么

3. **混淆点**：你最容易混淆哪里？
   - 平稳 vs 没有趋势
   - 弱平稳 vs 强平稳
   - 白噪声 vs 平稳序列
   - 差分为什么能帮助平稳

4. **例子判断**：如果一条序列均值一直上升，但波动幅度差不多，你觉得它通常算平稳吗？
   - 算，因为波动幅度稳定
   - 不算，因为均值随时间变
   - 要看模型和定义
   - 不确定

根据回答分流：不懂随机过程 → 先讲“每个时间点都是一个随机变量”；只混淆弱/强平稳 → 直接对比定义、边界和例子。
