# systematic-planning

把模糊目标转成可执行、可复盘、可调整的系统计划。适用于学习规划、考研/考试规划、项目规划、能力建设路线，以及把方法论沉淀为 Claude Code skill。

## 为什么需要这个

很多计划失败，不是因为用户不努力，而是因为计划只是一张漂亮日程表：目标模糊、成果不清、任务不是动作级、没有复盘和缓冲。

这个 skill 做的事：先把目标改写清楚，再拆成果、阶段、本周任务和日行动，最后加入 if-then 补救、最低保底任务和周复盘机制。它关注的是一个能持续运行的规划系统。

## 核心理念

```text
目标 → 成果 → 阶段 → 周计划 → 日行动 → 复盘 → 调整
```

- 先拆成果，再排日程
- 日任务必须动作级，带完成标准
- 学习计划必须包含提取练习和间隔复习
- 考研计划必须围绕真题、错题、背诵、模考、复盘
- 项目计划必须包含交付物、里程碑、依赖、风险、验收标准
- 不把计划排满，要有缓冲和最低保底任务

## 用法

```text
帮我制定一个三个月学统计学的计划
```

```text
我要准备考研，帮我系统规划
```

```text
帮我规划一个项目，从目标拆到本周任务
```

```text
我想把这套方法论做成 skill，先帮我规划结构
```

## 你会得到

默认输出结构：

```text
# 规划总览

## 1. 目标重写
## 2. 当前状态与关键约束
## 3. 核心成果拆解
## 4. 阶段计划
## 5. 本周计划
## 6. 日任务模板
## 7. 复盘机制
## 8. 风险与 if-then 方案
## 9. 下一步 24 小时行动
```

如果是 skill 设计，会改用：

```text
# Skill 设计规划

## 1. Skill 目标
## 2. 触发场景
## 3. 输入字段
## 4. 澄清问题
## 5. 内部工作流
## 6. 参考文件设计
## 7. 输出格式
## 8. 质量检查
## 9. 失败模式
## 10. 下一步行动
```

## 适用场景

- 学习一门课、掌握一项技能、建立学习路线
- 考研、资格证、期末考试等备考规划
- 软件、产品、内容、运营等工作/项目排期
- 写作、编程、表达、销售等长期能力建设
- 把方法论、流程、经验沉淀为 Claude Code skill

## 不适用

- 单纯事实问答
- 简单建议，不需要完整规划
- 用户已经有明确任务列表，只需要机械执行
- 纯代码实现计划；这类任务优先使用代码实现相关流程
