## 2. 学习计划模板

适用于学习一门知识、掌握一个技能、建立学习路线。

```markdown
# 学习计划

## 1. 学习目标

我想在【截止时间】前，掌握【知识/技能】，达到【可测标准】，用于【应用场景】。

## 2. 当前基础

- 已掌握：
- 薄弱点：
- 可用时间：
- 学习资源：
- 主要风险：

## 3. 学习成果

| 成果 | 验收标准 |
|---|---|
| 知识框架 | 能闭卷画出核心结构 |
| 基础练习 | 能独立完成基础题/案例 |
| 输出作品 | 能产出笔记、项目、讲解或作品 |
| 复习系统 | 有错题/卡片/复测记录 |

## 4. 阶段安排

| 阶段 | 目标 | 学习方式 | 输出 | 验收标准 |
|---|---|---|---|---|
| 入门框架 | 建立整体地图 | 看课/读书 + 提纲 | 知识地图 | 能讲清主线 |
| 主动练习 | 把知识转成能力 | 做题/案例/小项目 | 练习记录 | 正确率或完成质量达标 |
| 提取复习 | 巩固和迁移 | 自测/复述/间隔复习 | 错题和复测记录 | 隔几天仍能做对或讲清 |
| 输出应用 | 用起来 | 项目/文章/讲解 | 作品 | 能被他人理解或使用 |

## 5. 本周学习任务

1. 输入任务：读/看【具体章节或课程】。
2. 提取任务：闭卷复述/自测【具体内容】。
3. 练习任务：完成【题目/案例/项目】。
4. 复习任务：复测【之前错题/卡片】。
5. 输出任务：写出【笔记/讲解/作品】。

## 6. 间隔复习安排

- D0：首次学习后立刻自测。
- D1：第二天复测关键点。
- D3：第三天或第四天复测错题。
- D7：一周后综合复测。

## 7. 日任务模板

- 输入：学习【具体材料】X 分钟。
- 提取：不看资料复述/默写【具体内容】X 分钟。
- 练习：完成【具体题目/案例】。
- 反馈：记录错因和下次策略。

## 8. 复盘

本周哪些方法真正提高了理解和正确率？哪些只是看起来努力？下周删掉低效动作。
```

```markdown
## 3. 输入字段

| 字段 | 是否必需 | 用途 |
|---|---|---|
| 目标 | 必需 | 判断输出方向 |
| 当前状态 | 可选 | 制定现实计划 |
| 截止时间 | 可选 | 安排节奏 |
| 约束 | 可选 | 风险控制 |

## 4. 澄清问题

最多问 3–5 个关键问题。缺失但可假设时先输出初版。

## 5. 内部工作流

1. 判断场景。
2. 收集必要输入。
3. 选择适配器或模板。
4. 生成结构化输出。
5. 执行质量检查。
6. 给出下一步行动。

## 6. 参考文件设计

| 文件 | 作用 |
|---|---|
| SKILL.md | 入口、触发、主流程 |
| references/xxx.md | 详细规则、模板或案例 |

## 7. 输出格式

默认输出哪些标题？哪些字段必须出现？

## 8. 质量检查

输出前检查：是否具体、可执行、可复盘、不过度提问、不过度展开。

## 9. 失败模式

| 失败模式 | 预防方式 |
|---|---|
| 触发过宽 | 写清不要使用的场景 |
| 输出空泛 | 增加验收标准和例子 |
| 文件过大 | 把详细内容放 references |
| 每次都问太多 | 设置澄清问题上限 |

## 10. 下一步行动

1. 确定 skill 名称。
2. 写 SKILL.md 主流程。
3. 补 references 文件。
```

## 9. 模板使用规则

- 不要一次输出所有模板；只选和用户场景最相关的模板。
- 用户目标模糊时，先用通用模板生成初版，并列明假设。
- 用户目标明确时，直接使用对应领域模板。
- 用户要求“简洁”时，只保留目标、阶段、本周、今天、复盘、风险。
- 用户要求“系统/详细/严谨”时，补充成果拆解、验收标准、风险和证据依据。
