# 系统规划主框架

## 1. 规划的基本定义

系统规划不是把时间表排满，而是建立一个闭环：

```text
目标 → 成果 → 阶段 → 周计划 → 日行动 → 反馈 → 调整
```

规划的目的不是证明用户自律，而是降低混乱、暴露风险、提高行动概率。

## 2. 目标分类

先判断用户目标属于哪一类：

| 类型 | 重点 |
|---|---|
| 考试型 | 分数、科目、真题、错题、模考、背诵 |
| 学习型 | 知识框架、练习、提取、间隔复习、反馈 |
| 项目型 | 交付物、里程碑、依赖、风险、验收标准 |
| 能力型 | 长期练习、反馈、作品、可迁移能力 |
| 混合型 | 同时处理考试、学习、项目或能力建设 |

目标类型决定计划结构。不要用同一个模板硬套所有场景。

## 3. 目标重写

把用户的模糊目标改写成：

```text
我想在【截止时间】前，完成【具体结果】，达到【可衡量标准】，用于【目的】。
```

例子：

```text
模糊目标：我要好好准备考研。
重写目标：我想在 2026 年 12 月考前，完成英语一 2010–2026 年真题二刷，阅读正确率稳定在 80% 以上，用于把英语分数稳定到 75 分以上。
```

项目例子：

```text
模糊目标：我要做一个规划助手。
重写目标：我想在 4 周内完成一个系统规划 skill 初版，包含目标澄清、阶段计划、周计划、日任务和复盘机制，用于以后反复生成学习、项目和考研计划。
```

## 4. 当前状态与约束识别

规划必须从现实出发。收集：

```text
当前水平：现在已经会什么？不会什么？
可用时间：每天/每周真实可用多少小时？
截止时间：什么时候必须交付或考试？
已有资源：教材、课程、资料、工具、导师、样例。
限制条件：工作、学校、家庭、身体、环境、金钱。
风险因素：拖延、基础弱、信息过载、估时错误、状态波动。
优先级：如果只能完成 60%，最重要的是什么？
```

如果信息不足但可以先规划，声明假设。

## 5. 成果拆解

不要从“每天做什么”开始，而要从“最终要交付/掌握什么”开始。

模板：

```text
最终目标：
核心成果 1：
验收标准：
核心成果 2：
验收标准：
核心成果 3：
验收标准：
```

例子：

```text
最终目标：完成一个可复用的系统规划 skill。
核心成果 1：SKILL.md 主入口。
验收标准：有明确触发条件、核心流程和输出格式。
核心成果 2：规划方法参考文件。
验收标准：能指导目标澄清、约束识别、阶段规划和复盘。
核心成果 3：输出模板。
验收标准：覆盖学习、考研、项目、skill 设计四类场景。
```

## 6. 阶段规划

推荐 3–5 个阶段，每个阶段都要有产出。

通用阶段：

```text
阶段 1：摸底与框架
阶段 2：系统学习 / 方案设计
阶段 3：强化训练 / 最小版本
阶段 4：模拟输出 / 测试迭代
阶段 5：冲刺交付 / 复盘归档
```

每个阶段写：

```text
阶段名称：
时间范围：
阶段目标：
关键任务：
阶段产出：
验收标准：
风险：
```

## 7. 周计划

周计划只解决最近一周，不要把远期细节排死。

模板：

```text
【本周目标】
本周要交付/掌握什么：

【关键任务】
1.
2.
3.

【指标】
数量指标：
质量指标：
反馈指标：

【风险】
最大风险：
应对方案：

【保底】
如果状态很差，最低必须完成：
```

## 8. 日任务

日任务必须是动作级，带完成标准。

坏写法：

```text
学英语
看数学
做项目
背专业课
```

好写法：

```text
精读 2018 英语一 Text 1，整理 10 个长难句。
完成概率论第 2 节 30 道题，标出错题原因。
写出 skill 输入字段 JSON 草案。
闭卷默写专业课第 3 章一级标题。
```

日计划模板：

```text
今日主目标：

任务 1：
预计时间：
完成标准：

任务 2：
预计时间：
完成标准：

任务 3：
预计时间：
完成标准：

今日最低保底任务：
今日复盘：
```

## 9. 复盘调整

每周复盘一次。

问题：

```text
1. 本周原计划是什么？
2. 实际完成了什么？
3. 哪些任务低估了耗时？
4. 哪些任务对目标最有帮助？
5. 哪些任务价值不高？
6. 下周应该保留什么？
7. 下周应该删掉什么？
8. 下周应该加强什么？
```

不要只问“我是不是不自律”，要问“计划哪里不符合现实”。

## 10. 规划输出的最低标准

一个合格计划必须让用户知道：

```text
我要达成什么？
为什么重要？
怎么判断完成？
分哪些阶段？
本周做什么？
今天做什么？
失败了怎么补救？
什么时候复盘？
下一步 24 小时做什么？
```
